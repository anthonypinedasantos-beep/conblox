# Conblox

A static, responsive community gaming discovery homepage built for GitHub Pages.

## Deploy with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for the Pages deployment and open the URL shown in Settings → Pages.

The site is plain HTML, CSS and JavaScript. No build step is required.

## Important notes

- The sign-up and log-in screens are front-end demonstrations only. They do not create accounts or collect credentials.
- The experience cards are sample content, not live games.
- The linked 2016 Roblox source repository is an old C++ engine/source project, not a website template. This site is an original frontend inspired by classic game-discovery layouts; it does not copy Roblox code, branding assets or proprietary services.
- Conblox is an independent project and is not affiliated with Roblox Corporation.
